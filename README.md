This repository implements an evolutionary algorithm designed to optimize protein–protein interactions by mutating amino acid sequences and evaluating their binding specificity using a mutual information (MI)-based scoring filter.
The project aims to identify potential molecular candidates with higher binding affinity to target proteins associated with diseases such as Parkinson’s. Although this version focuses on the computational pipeline, future iterations will integrate experimentally validated binding data to improve accuracy.


Main Files:

evolutionary_algorithm.py – core algorithm performing iterative mutation, selection, and fitness evaluation

mi_smart_filters.py – computes mutual information-based specificity scores for evolved sequences

interactingProteins.tsv – list of known interacting proteins used as input for filtering

P37840.fasta – base sequence file (target protein)

original_asyn.fasta – initial alpha-synuclein sequence used for mutation

mutated.fasta – output of evolved protein sequences generated by the algorithm

requirements.txt – required dependencies (e.g., Biopython, NumPy, Pandas)

pic_specificity_algorithm/ – contains modules and helper scripts for MI computation and evolutionary logic




The algorithm begins by loading the target protein FASTA sequence from `original_asyn.fasta`. It then generates random amino acid substitutions to create new variant sequences, which are evaluated using the PIC specificity algorithm to measure co-evolution and binding potential between candidate and target proteins. The highest-scoring variants are retained across generations, and the resulting evolved candidates are saved to `mutated.fasta` for further validation or docking analysis.

This is an ongoing research implementation. The current pipeline successfully performs mutation and filtering but has not yet produced statistically significant molecular candidates. Future work will focus on integrating structural scoring (such as delta-G estimation) and combining MI scores with AlphaFold-based structural predictions to improve accuracy and reliability.
